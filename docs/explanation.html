Explanation

A take, then a grade

jitters is closer to a film pipeline than to a screen recorder. One command looks like “prompt in, MP4 out”, but the work splits in two so you can change the look without performing the scene again.

Capture is the take. Render is the grade.

Two passes

Capture is the take. An isolated agent-browser session opens Chrome, sets a 1440×900 viewport, and records the page while a judgment backend chooses the next action. When the loop stops, the project directory holds footage, a mouse track, a semantic timeline, and a style file.

Render is the grade. A 2D compositor reads those artifacts, crops and zooms around timeline targets, paints the framed window onto the styled canvas, draws a cursor along a Bézier fitted through the samples, and encodes with ffmpeg. No browser is involved.

That is why jitters render ./demo.jitters can change cursor size, zoom, motion blur, padding, or background without launching Chrome. Recapture is only for a different story on the page.

Why the capture has no cursor

If the pointer were burned into capture.mp4, restyle would be a second-rate overlay: you could not change size, path smoothing, ripples, or shutter, and you could not hide the OS arrow. jitters records page pixels only (record start without --cursor) and samples mousemove / mousedown / mouseup into cursor.json.

The compositor then draws a synthetic cursor. The path is not click-to-click shortcuts. Human-like moves, loops, and overshoots in the samples stay, because the curve is fitted through the whole track. Click ripples come from button-down samples. Motion blur averages shutter samples of the camera transform and of the cursor.

timeline.json is a different document: it names click, type, and scroll events with element boxes so the camera knows what to zoom toward. It is not the pointer path.

Why the agent cannot invent text

The judgment layer answers structured questions (choices and probabilities). It does not generate free text. Typing “whatever seems right” would make demos lie, leak prompt leftovers, or walk into fields the user never named.

So jitters extracts a closed set from the prompt before the loop starts. Every type/navigate choice includes none. If the backend picks an action whose value is none, or a value outside the set, the run finishes. That is a successful stop, not a license to improvise. Quote the strings you want typed.

Code owns control flow

Each step is one judgment request with static question text. Untrusted page snapshot, title, and body text travel in state only — they are never spliced into instructions, so a page cannot rewrite the questions.

The program consumes only the next_action branch. Speculative answers on unused branches are ignored. Code, not the model, decides when to snapshot, when to hold for zoom-out, when to refuse a repeat click or a second visit to the same URL, and when three identical actions mean the run is stuck.

TypeSafe System One is the native backend. Vercel AI Gateway, OpenRouter, and Cloudflare AI Gateway answer the same closed-set questions as JSON. The loop does not change; only the client does. API keys stay in the environment so they cannot leak into jitters.toml, stdout, or the encoded video.

Look is data

1920×1080 padding 24 radius 16 zoom 1.6 cursor 32 shutter 0.5

Default tokens live in style.json: 1920×1080 canvas, inset rounded window, drop shadow, dark-to-blue gradient, zoom 1.0→1.6 with a cubic envelope, cursor size, ripple color, motion-blur shutter. Because those values are data, a later export can look like a different product film from the same take.

The CLI is the whole product surface. There is no post-record GUI, no camera bubble, and no voiceover track. Agents parse one JSON object and, if the look is wrong, edit JSON and render again.
