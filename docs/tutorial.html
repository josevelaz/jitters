Tutorial / Take 01

Capture your first demo

This lesson walks a new machine from a clone of jitters to a framed MP4. You will record example.com, click “More information…”, and open the export.

The goal

When you finish, you will have:

  • A JSON result on stdout with status done.
  • An MP4 next to a *.jitters/ project folder.
  • Raw page footage in that folder with no pointer drawn on it.
01

Build the CLI

  1. Clone the repository and install JavaScript dependencies.

    shell 
    git clone https://github.com/josevelaz/jitters.git
cd jitters
pnpm install

  2. Compile TypeScript. The binary is dist/cli.js.

    shell 
    pnpm build
node dist/cli.js --help

    You should see usage for <prompt>, render, and config. Help does not need API keys or extra binaries.

02

Install the external binaries

  1. Put ffmpeg on your PATH. Confirm with ffmpeg -version.

  2. Install agent-browser and its Chrome:

    shell 
    agent-browser --version
agent-browser install
03

Export a provider key

The default backend is TypeSafe. Export the key in the shell that will run jitters — not in a file in this repo.

shell 
export TYPESAFE_API_KEY="your-key"

Warning

Never put API keys in jitters.toml, video, stdout, or the repository.

To use another backend instead, see Switch the judgment provider.

04

Run the capture

Quote the link text so it becomes a type/click candidate. Pass the starting URL with --url.

shell 
node dist/cli.js "Open https://example.com and click 'More information...'" --url https://example.com

Wait until stdout prints one JSON object. status should be done. If a dependency is missing, the process exits nonzero and names it on stderr.

05

Look at the result

  1. Open the path in the JSON out field. You should see a 1920×1080 (by default) framed window on a dark-to-blue background, a synthetic cursor, and a zoom toward the link.

  2. Open the project directory. It contains:

    • capture.mp4Page pixels only, no cursor.
    • cursor.jsonSampled mouse positions.
    • timeline.jsonClick/type/scroll events with boxes.
    • style.jsonCompositor tokens for the next render.

Note

You now have a restylable take. Next: re-render without Chrome.
