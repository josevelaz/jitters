How-to

Solve a specific job

Each recipe assumes you can already run node dist/cli.js --help. Swap that for jitters if the binary is on your PATH.

Quote the text the agent should type

The loop never invents copy. It only types strings extracted from the prompt (quoted text, or phrases after “search for” / “type” / “enter”).

node dist/cli.js "type 'hello@example.com' into the email field and submit" --url https://example.com

If you need a URL in the closed set, put the https://… in the prompt or pass --url.

If the model chooses type or navigate but the matching choice is none, jitters finishes instead of fabricating a string or URL.

Restyle a take without recapturing

Use this when the story is right and only the look should change.

  1. Edit <slug>.jitters/style.json. Typical knobs: cursor.size, zoom.scale, motionBlur.samples, padding, background.
  2. Recomposite:
node dist/cli.js render ./demo.jitters
node dist/cli.js render ./demo.jitters --style ./custom.json --format 1280x720 --bg "#111111" --out ./demo-v2.mp4

--style replaces the style file for that export. --format and --bg override one export. Chrome is not launched. Render only needs ffmpeg.

Recapture only if the page footage or the mouse track must change.

Switch the judgment provider

The step loop is the same for every backend. Only the client changes.

node dist/cli.js "show the signup flow" --url https://example.com --provider openrouter
node dist/cli.js "show the signup flow" --url https://example.com --provider vercel --model openai/gpt-4o-mini
node dist/cli.js "show the signup flow" --url https://example.com --provider cloudflare --model openai/gpt-4o-mini
ProviderEnvironment
typesafe (default)TYPESAFE_API_KEY
vercelAI_GATEWAY_API_KEY or VERCEL_OIDC_TOKEN
openrouterOPENROUTER_API_KEY
cloudflareCLOUDFLARE_API_TOKEN and CLOUDFLARE_ACCOUNT_ID

Gateway providers default to model openai/gpt-4o-mini unless you pass --model. TypeSafe uses the SDK default (jev-latest) unless --model is set. Optional Cloudflare gateway id: CLOUDFLARE_AI_GATEWAY_ID (default default), or cloudflare_gateway in config.

Set defaults in jitters.toml

First existing file wins (not merged): ./jitters.toml, then $XDG_CONFIG_HOME/jitters/config.toml (or ~/.config/jitters/config.toml). Flags override the file.

node dist/cli.js config            # JSON: which file is active
node dist/cli.js config --skill    # print the skill for editing that file
# url = "https://example.com"
# max_steps = 20
# format = "1920x1080"
# provider = "typesafe"
# model = "openai/gpt-4o-mini"

[style.zoom]
scale = 1.6

[style.cursor]
size = 32

A [style] table is copied into a new project’s style.json at capture. An existing style.json stays until recapture or --style. Never put API keys in the TOML file.

Use jitters from an agent

Point the agent at SKILL.md in the repo. Capture once from the user prompt, parse stdout JSON, then edit style.json and run render for look changes. Keep keys and agent-browser state out of the video, stdout, and the repo.
