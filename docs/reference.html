Machinery

Values below match the current CLI. Flags override user config. User config is not merged across files.

Commands

InvocationWhat it does
jitters [options] <prompt>Capture, then composite. Needs provider auth, agent-browser, and ffmpeg.
jitters render <project> [options]Recomposite an existing *.jitters directory. Needs ffmpeg only.
jitters configPrint JSON for the active config file (path, source, resolved values).
jitters config --skillPrint the config-editing skill to stdout.
jitters --helpPrint usage. No deps required.

Flags

FlagMeaning
--url <url>Starting URL. Also added to the closed URL candidate set.
--out <path>Output MP4 file, or a directory. Default: <slug>.mp4 next to <slug>.jitters/ in cwd. A directory puts both under that directory.
--project <name>Project slug. Default: derived from the prompt (max 60 filesystem-safe characters).
--style <path>Replace the project style for this export.
--max-steps <n>Max agent steps. Default 20, cap 40. Integers ≥ 1.
--provider <id>typesafe (default), vercel, openrouter, or cloudflare. Aliases include jev, ai-gateway, cf.
--model <id>Model for the selected provider. Gateway default openai/gpt-4o-mini.
--format <WxH>Export size override. Also accepts 720p, 1080p, 4k.
--bg <color>Background override for one export.

Unknown flags fail. Capture without a prompt prints help and exits nonzero.

Stdout JSON

One JSON object, then a newline. Logs go to stderr.

{
  "status": "done",
  "out": "/abs/demo.mp4",
  "project": "/abs/demo.jitters",
  "durationMs": 12345,
  "steps": []
}
statusExitMeaning
done0Task complete, finish, or a closed-set none / already-visited stop.
stuck0Three identical actions in a row. Still exports whatever was captured.
max_steps0Hit --max-steps. Still exports.
error1Failure. error string is set. May still include out / project if artifacts exist.

steps is an array of { index, action, target?, value?, url?, note? }.

Project files

Capture writes <slug>.mp4 plus:

FileContents
capture.mp4Page pixels at 60 fps. No pointer, no ripples. Viewport 1440×900.
cursor.jsonArray of { tMs, x, y, button? }. Dense samples; curves are many points, not two endpoints.
timeline.jsonSemantic events { tMs, kind, box?, ref?, value?, url? } for zooms. Not the cursor path.
style.jsonCompositor tokens for this take.

Default style.json

{
  "canvas": { "width": 1920, "height": 1080 },
  "padding": 24,
  "radius": 16,
  "shadow": { "x": 0, "y": 24, "blur": 80, "color": "rgba(0,0,0,0.35)" },
  "background": {
    "type": "linear-gradient",
    "from": "#0b1020",
    "to": "#1d4ed8",
    "angle": 135
  },
  "zoom": {
    "scale": 1.6,
    "inMs": 700,
    "holdMs": 800,
    "outMs": 700,
    "skipAbove": 0.4
  },
  "cursor": { "size": 32, "tension": 0.5 },
  "ripples": {
    "enabled": true,
    "durationMs": 600,
    "color": "rgba(96,165,250,1)",
    "maxRadius": 44
  },
  "motionBlur": {
    "enabled": true,
    "samples": 8,
    "shutter": 0.5,
    "camera": true,
    "cursor": true
  }
}

Zoom is skipped when the target box covers more than skipAbove of the viewport (default 40%). Cursor path tension must not collapse loops: the compositor fits a cubic Bézier through the sampled track (Catmull-Rom → Bézier). Ripples come from button-down samples, not from timeline clicks.

Agent stop conditions

  • task_complete noul ≥ 0.7
  • next_action is finish (or unrecognized)
  • type / navigate / click with choice none, or a value outside the closed set
  • Navigate to a URL already visited this run, or click a ref already clicked
  • Three identical history entries
  • --max-steps reached

Page snapshot, title, and body text travel in request state only. They are never concatenated into question instructions. After the last action, capture holds long enough for the zoom envelope (in + hold + out) to play out.
